MELAMCODE TEMPLE MANAGER v1.0.16 - WINDOWS 32-BIT x86
=======================================================

ഈ പതിപ്പിലെ പുതിയ മാറ്റങ്ങൾ
---------------------------
1. Statements & Reports -> "തീയതി–വഴിപാട് ഭക്തരുടെ പട്ടിക" എന്ന പുതിയ report ചേർത്തു.
2. ഒരു വഴിപാട് തീയതിയും ഒരു പൂജ / വഴിപാടും തിരഞ്ഞെടുക്കാം.
3. ആ തീയതിയിൽ ആ വഴിപാട് Active ആയി ബുക്ക് ചെയ്തിട്ടുള്ള എല്ലാ ഭക്തരുടെയും പേര്,
   നാള്, ഫോൺ, രസീത് നമ്പർ, വഴിപാട് എണ്ണം എന്നിവ A4 പട്ടികയായി ലഭിക്കും.
4. പട്ടിക PDF, Print, CSV എന്നീ രൂപങ്ങളിൽ എടുക്കാം.
5. Cancel / Refund ചെയ്ത ബുക്കിംഗുകൾ ഈ പട്ടികയിൽ ഉൾപ്പെടില്ല.
6. Dashboard-ലെ "മാസത്തിലെ നീക്കിയിരിപ്പ്" item നീക്കം ചെയ്തു.

FULL WINDOWS VERSION
--------------------
1. Full ZIP പുതിയ folder-ലേക്ക് പൂർണ്ണമായി Extract ചെയ്യുക.
2. win-unpacked folder തുറക്കുക.
3. "Melamcode Temple Manager.exe" double-click ചെയ്യുക.
4. Dashboard top-right-ൽ "UPDATED · v1.0.16" കാണുന്നുണ്ടെന്ന് ഉറപ്പാക്കുക.

SMALL UPDATE
------------
1. Application പൂർണ്ണമായി Close ചെയ്യുക.
2. Small Update ZIP പഴയ application folder-ലേക്ക് Extract ചെയ്യുക.
3. APPLY-UPDATE-v1.0.16.cmd double-click ചെയ്യുക.
4. SUCCESS message വന്നശേഷം application തുറക്കുക.

നിലവിലുള്ള database Windows AppData-ൽ തുടരും. Update തുടങ്ങുമ്പോൾ application
database-ന്റെ പ്രത്യേക v1.0.16 safety backup സ്വയം സൃഷ്ടിക്കും.
